# `src/ant/dron/`

- `ant_ciber_dron.py` modela las seis patas, sus componentes virtuales, el turborreactor y la fuente de poder. `AntCiberDron.buscar(palabra)` usa el evaluador recibido en el constructor.
- `modulo_idioma.py` registra léxico, gramática y fonética en inglés y español. Hace falta un `ExpertoParlante` certificado en el idioma seleccionado. Acepta una conexión SQLite para conservar los registros.
